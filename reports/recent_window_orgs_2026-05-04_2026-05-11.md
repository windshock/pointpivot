# 조직별 최근 7일 흔적 재점검 (2026-05-04 ~ 2026-05-11)

> 생성 방식: DDG `timelimit='w'` 검색 후 후보 원문을 직접 fetch해 `datePublished` / `published_time` / 게시일 메타데이터를 확인했다.
>
> 목적: Cluster#1~#3의 최근 검색 노출이 실제 최근 게시글인지, 아니면 과거 source 재노출·검색 인덱스 오염인지 분리한다.

## 결론

- **Cluster#1:** 최근 게시일 기준 후보 1건 확인. `chunggong.or.kr` 상세 페이지의 `article:published_time`이 `2026-05-06T14:59:52+09:00`이고, 제목에 `@abab1768` 및 선불유심/내구제 계열 문구가 함께 노출됐다.
- **Cluster#2:** 최근 7일 게시일 기준 검증 후보는 확인되지 않았다. `@YY77882` 검색 노출은 있었지만 원문 기준으로는 2025-11~2026-02 stale source 또는 fetch/source-date 미확인 후보였다.
- **Cluster#3:** 기존 최근-window 재실행 결과와 결론 동일. `@GO174`/`@Muo52S` 노출은 계속 보이나 최근 7일 게시일 기준 신규 source는 확인되지 않았다.
- **IP 피벗:** 이번 확인에서 `chunggong.or.kr` 원문은 작성자 IPv4를 노출하지 않았다. 따라서 신규 IP IOC로 승격하지 않는다.

`@YY77882` 관련 검색 결과는 계속 노출되지만, 최근 7일 게시일 기준으로 확인된 원문은 없었다. 일부 결과는 오래된 쇼핑몰/포럼 source 또는 검색 URL 자체의 키워드 노출이었다. 이 결과는 Cluster#2가 사라졌다는 의미가 아니라, **이번 window에서 최근 게시일 기준 신규 증거가 없었다**는 뜻이다.

## 운영 메모

- 검색 provider의 "최근" 결과는 게시일 기준 최근성과 다르다.
- 최근 활동으로 기록하려면 원문 게시일과 IOC/행위 키워드가 같은 source에서 확인되어야 한다.
- 통신사/주거형 IP는 작성자 IP가 직접 노출되지 않는 한 신규 차단 IOC로 승격하지 않는다.
- 이번 `chunggong.or.kr` 후보는 Cluster#1 활동 지속성 근거로만 사용하고, 신규 IP 피벗 근거로는 사용하지 않는다.
