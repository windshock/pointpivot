# 신규 조직/핸들 후보 발굴 (2026-05-11)

> 목적: 기존 클러스터 IOC가 아니라 행위 키워드 기반으로 최근 7일 신규 후보를 찾고, 검색 스니펫이 아닌 원문 게시일과 본문 IOC를 확인한다.
>
> 범위: `선불유심내구제`, `유심내구제`, `선불폰`, `기프티콘/포인트/소액결제 현금화`, `계좌매입`, `통장협박`, `가개통`, `폰테크` 계열 쿼리.

## 결론

- 신규 USIM/loan spam 후보 3개 핸들을 확인했다: `@holysim`, `@rnfma9`, `@sk11400`.
- 연결 홍보 도메인 후보는 `holysim.isweb.co.kr`, `rnfma9rnfma9.isweb.co.kr`, `sk11400.isweb.co.kr`이다.
- 최근 원문 source는 `tvo.kr`와 `dgcaa.or.kr` 게시판이며, 게시일 메타데이터는 2026-05-07~2026-05-11 범위 안에 있다.
- 홍보 도메인 2개는 직접 접근 시 403 Forbidden을 반환했다. 원문 게시글에 URL이 직접 노출됐다는 사실만 기록한다.
- 추가 IP 노출 페이지 확인으로 `@rnfma9` 작성자 IP `121.170.203.144`, `@sk11400` 작성자 IP `168.126.234.232`를 확인했다.
- 기존 Cluster#1과 업종/게시판 스팸 패턴은 유사하지만, 현재 공유 IP·공유 핸들·공유 홍보 도메인이 확인되지 않아 별도 신규 후보로 둔다.

## 보수적 판정

- `@media`, `@context`, `@type`, `@login` 등은 HTML/CSS/JSON-LD 토큰으로 보고 IOC에서 제외한다.
- `2Fholysim.isweb.co.kr`는 URL 인코딩 파편으로 보고 별도 도메인 IOC에 등록하지 않는다.
- `@sk11400`은 과거 `118.235.12.181` 자동 조사 초안의 검색 스니펫에도 보였지만, 이번에는 `tvo.kr` 상세 원문과 `maribel.co.kr` 작성자 IP 노출 원문에서 별도 확인된 신규 후보로 기록한다.
- DCinside 검색 결과는 `kkone (211.201)`처럼 부분 IP만 보이며, 페이지 HTML의 `104.28.164.10`은 CDN/페이지 자산 값으로 보여 작성자 IP로 등록하지 않는다.
- 이번 신규 후보는 기존 Cluster#1과 같은 업종이지만, 행위자 동일성은 아직 확인되지 않았다.

- `168.126.234.232`는 `@sk11400` 직접 게시 증거로만 유지하고, 최신성은 2026-03-26 source로 제한한다.
