# 통신사별 IP 대역 참고표

> 출처: 2026-05-11 사용자 제공 자료.
>
> 용도: 조사 보고서의 `인프라 유형` 추정, CGNAT/통신사 대역 오탐 방지, 모바일/유선 carrier context 보강용 참고자료. 이 파일만으로 악성 여부를 판단하거나 차단 목록에 추가하지 않는다.

## 사용 원칙

- `KR_MOBILE` / `KR_RESIDENTIAL` 추정 보조자료로 사용한다. 실제 판정은 게시글 본문, 작성자 IP, IOC, 관리자 로그 등 직접 증거가 우선이다.
- 통신사 대역은 CGNAT·동적 할당·기업/제휴사 공용 인프라와 섞일 수 있으므로, 대역 매칭만으로 클러스터 귀속 또는 위협 판정을 하지 않는다.
- `확인 필요` 표기는 원본 이미지상 오기 또는 판독 오류 가능성이 있는 항목이다. 자동화에 넣기 전에 별도 검증한다.
- 아래 값은 CIDR이 아니라 prefix 메모다. 예: `39.7`은 `39.7.*.*`, `118.235.8`은 `118.235.8.*` 수준의 참고값이다.

## 프로젝트 적용 아이디어

| 활용 지점 | 적용 방식 |
|---|---|
| 조사 보고서 | IP가 아래 prefix에 맞으면 `인프라 유형`에 `KR_MOBILE 추정` 또는 `KR_RESIDENTIAL 추정`을 적고 근거로 이 파일을 링크한다. |
| 오탐 방지 | KT/LGU+/SKT 모바일·유선 대역이면 "통신사 대역 자체는 위협 근거 아님"을 보고서 특이사항에 남긴다. |
| lifecycle/TTL | 모바일 대역은 `KR_MOBILE` 기본 TTL 60일을 우선 고려하되, 직접 게시 증거가 없으면 `DONE`으로 승격하지 않는다. |
| 자동화 후보 | 향후 `scripts/utils.py`에 prefix 매칭 helper를 추가해 조사 초안의 `인프라 유형` 자동 제안을 만들 수 있다. |
